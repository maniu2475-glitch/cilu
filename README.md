# 词炉 · 单词维护器

把一个背完的单词书，变成能每天维护、扩展、激活的系统。

单词书背完只代表「认识过」，离「记得住、用得出」还差三步。词炉就是干这三步的：

- **维护**：已背过的词按遗忘曲线循环复习，不再从零重来
- **扩展**：只收真题里影响理解 / 常考同义替换 / 作文能用的词，三条都不满足就放弃
- **激活**：用真题原句做挖空回填，把「认脸」变成「用得出」
- **检验**：每周抽 30 词做中→英产出测试，低于 80% 自动收紧全库复习间隔

## 安装到手机

1. 用手机浏览器打开本仓库的 Pages 地址
2. 浏览器菜单 →「添加到主屏幕」
3. 之后像普通 App 一样打开，**断网也能用**

## 四个模块

| 模块 | 干什么 |
|---|---|
| 今日 | 到期队列总览、三项目标进度、周测入口 |
| 收词 | 手动录入单词，强制选收录理由，带词族/搭配/例句 |
| 回填 | 从带 `___` 的例句抽 10 句，填完即时判对错 |
| 错词 | 答错 2 次自动进错词本，连对 3 次才放出 |

## 调度规则

四档自评（忘了 / 勉强 / 记得 / 秒答）映射到简化 SM-2：

- 忘了 → 间隔归零，10 分钟后再撞，ease −0.2
- 勉强 → 间隔 ×0.6，明天再见，ease −0.12
- 记得 → 按间隔表 × ease 计算新间隔
- 秒答 → 在「记得」基础上再 ×1.35

周测低于 80% 时，全库间隔 ×0.75。

## 数据

全部存在浏览器 `localStorage`，不上传任何服务器。**换设备或清缓存会丢**，请在菜单里定期「导出备份」。

## 本地开发

```bash
# 起静态服务（任意静态服务器均可）
node -e "require('http').createServer((q,s)=>{const f=require('path').join('.',q.url==='/'?'index.html':q.url);require('fs').readFile(f,(e,d)=>{if(e){s.writeHead(404);return s.end()}s.writeHead(200);s.end(d)})}).listen(8791)"

# 端到端验收（需 Playwright + Chromium）
npm i -D playwright
node verify.mjs
```

图标重新生成：`python make_icons.py`

## 技术

纯 HTML + CSS + JS 单文件，零依赖、零构建。PWA 三件套提供离线能力。
